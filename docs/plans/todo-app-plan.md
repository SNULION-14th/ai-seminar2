# 📋 OneFocus: 초경량 UX 중심 Todo 앱 기획안

## 1. 프로젝트 개요
* **서비스명**: OneFocus
* **슬로건**: *"적는 데 1초, 끝내는 데 온전한 몰입"*
* **핵심 타깃**: 할 일 관리 앱의 과도한 옵션(태그, 날짜, 폴더 등)에 피로감을 느끼는 미니멀리스트 & 학생/직장인
* **핵심 가치**: **인지적 마찰 0 (Zero Cognitive Friction)** — 앱 실행부터 입력까지 단 한 번의 불필요한 터치도 없앰

---

## 2. 핵심 UX 설계 원칙
1. **Zero-Click Input**: 앱 실행 시 텍스트 입력창이 즉시 포커스되어 바로 타이핑 가능
2. **Visual Dopamine (작은 성취감)**: 완료 시 부드럽고 경쾌한 인터랙션 및 성취감 부여
3. **No Guilt (죄책감 없는 내일)**: 지나간 미완료 항목에 대한 시각적 페널티 대신 부드러운 이월(Rollover) 경험 제공

---

## 3. 주요 기능 (MVP Scope)

| 기능 | 세부 내용 | UX 포인트 |
| :--- | :--- | :--- |
| **초고속 할 일 추가** | 엔터 키 한 번으로 즉시 등록 | 타이핑 후 `Enter` 입력 시 리스트 추가 및 즉시 다음 입력 대기 |
| **직관적 상태 제어** | 체크박스 및 상태 토글 | **체크 완료**: 부드러운 취소선 처리<br>**삭제**: 간편한 원터치 삭제 |
| **심플 2분할 뷰** | 오늘(Today) / 나중에(Someday) | 복잡한 달력 대신 직관적인 2단계 분류 |
| **로컬 퍼스트 (Offline First)** | LocalStorage 기반 데이터 영속화 | 별도 로그인 없이 즉각적인 반응속도(0.1s) 보장 |

## 4. 화면 구성 (Single-Screen Architecture)

복잡한 탭이나 뎁스 이동 없이 단일 화면에서 모든 플로우가 완결됩니다.

```text
┌──────────────────────────────────────────┐
│  OneFocus                 ⚙️ (Settings)   │
│  2026. 09. 19 (토)                       │
│  ━━━━━━━━━━●━━━━━ 3 of 5 done (60%)      │ <- 진행률 프로그레스 바
├──────────────────────────────────────────┤
│  [ 오늘 할 일 (2) ]                       │
│  [ ] 1. 알고리즘 문제 풀기          [⭐]  │ <- 탭하여 Focus 모드 전환
│  [ ] 2. 3시 팀 미팅 참석                 │
│                                          │
│  [ 완료된 항목 (3) ]   (접기/펼치기)     │
│  [x] ~~아침 러닝 3km~~                   │
│  [x] ~~세미나 자료 검토~~                │
│                                          │
├──────────────────────────────────────────┤
│  + 할 일을 입력하세요...           [Enter]│ <- 하단 고정 입력 필드
└──────────────────────────────────────────┘
```

## 5. 차별화 포인트 (Differentiators)

1. **"Now (지금 하나만)" 몰입 모드**:
   - 중요한 작업 옆의 별(`⭐`) 아이콘 클릭 시 해당 할 일 1개와 미니 타이머만 표시
   - 다른 항목을 블러 처리하여 주의 분산 방지
2. **자정의 소프트 리셋 (Gentle Morning Review)**:
   - 전날 미완료 항목을 죄책감 없이 오늘 목록으로 이월할지 결정할 수 있는 부드러운 넛지 제공
3. **로그인 없는 즉시 시작**:
   - 브라우저 로컬 저장소 우선으로 마찰 없는 온보딩 제공
