# 외부 연동 규칙

## Google Calendar

- 목적: 참석자 가용 시간 계산과 확정 이벤트 생성.
- 일정 조회 결과는 `busy` 구간으로만 정규화한다.
- 제목, 설명, 위치, 참석자 목록은 화면·로그·분석 데이터에 저장하지 않는다.
- 이벤트 생성은 주최자의 명시적 확정 뒤에만 실행한다.

## GitHub

- 목적: 연결된 이슈·PR의 제목, 상태, 링크를 회의 맥락으로 제공.
- 사용자가 지정한 저장소·이슈·PR만 조회한다.
- PR 생성, 댓글, 병합은 기본 기능에 포함하지 않으며, 쓰기 기능은 실행 직전 확인한다.

## 공통 실패 처리

- 연결 만료: 재연결 CTA를 제공하고 기존 조율 데이터는 유지한다.
- 권한 부족: 필요한 최소 권한을 설명하고 다른 기능은 계속 사용할 수 있게 한다.
- API 실패: 가짜 결과를 만들지 않고 재시도 버튼을 제공한다.
