# 제품 기획: 맞는 시간

## 한 줄 소개

Google Calendar의 빈 시간을 비교해 여러 사람이 빠르게 약속 시간을 확정하고, GitHub 작업 맥락까지 함께 확인하는 일정 조율 서비스.

## 문제와 사용자

- 팀·동아리 구성원은 "언제 돼?" 메시지와 캘린더 확인을 반복한다.
- 주최자는 각자의 응답을 조합하고 확정 뒤 다시 캘린더 일정을 만들어야 한다.
- 개발 팀은 회의 전 관련 GitHub 이슈·PR을 다시 찾아야 한다.

## MVP

1. Google Calendar 연결 및 바쁨/비어 있음 조회
2. 조율 생성: 제목, 참석자, 기간, 소요 시간, 선호 시간대
3. 공통 빈 시간 후보 세 개 추천
4. 후보별 가능·애매함·불가 응답과 주최자 확정
5. 확정 일정을 Google Calendar에 생성
6. GitHub 이슈·PR 링크를 조율에 연결

## 성공 기준

- 조율 생성부터 확정까지 걸리는 시간
- 초대받은 사람의 응답률
- 추천 후보에서 확정된 비율
- 확정 후 캘린더 저장 비율
