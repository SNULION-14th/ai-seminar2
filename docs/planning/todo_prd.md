# 📱 [PRD] 사용자 경험(UX) 중심 미니멀 Todo 서비스: "FlowDo"

> **"기록은 생각의 속도로 가볍게, 실행은 오늘의 3가지에 명확하게, 마무리는 죄책감 없이 깨끗하게."**  
> 기존 할 일 관리 도구의 과도한 설정(날짜, 태그, 프로젝트 등)과 쌓여가는 미완료 태스크로 인한 인지 과부하(Cognitive Overload) 및 할 일 부채감(Task Debt)을 해결하기 위한 극도의 사용자 경험 중심 Todo 서비스 명세서입니다.

| **타겟 사용자** | • 할 일 목록을 정리하다 지쳐 포기한 경험이 있는 직장인/학생/1인 메이커<br/>• 복잡한 노션/지라 대신 즉각적이고 마찰 없는 할 일 관리를 원하는 사용자<br/>• 수많은 미완료 할 일에 심리적 압박감(Task Anxiety)을 느끼는 사용자 |

## 2. 차별화 포인트 (Differentiators & Value Proposition)

기존 Todo 앱(Todoist, TickTick, Apple Reminders 등)과의 결정적인 4가지 차별화 요소:

### ① 제로 프릭션 자연어 입력 (Zero-Friction Quick Capture)
- **기존 문제:** 할 일 하나를 적으려면 마감일, 우선순위, 태그, 프로젝트 선택 등 수많은 팝업과 클릭을 거쳐야 함.
- **FlowDo 솔루션:** 단 하나의 입력창에 자연스럽게 타이핑하고 `Enter`만 누르면 등록 끝 (예: `"내일 3시 디자인 미팅"`, `"!핵심 기획서 초안"`). 0.5초 안에 생각의 흐름을 끊지 않고 캡처.

### ② '오늘의 집중 3' 원칙 (Rule of 3 Focus)
- **기존 문제:** 20~30개의 할 일이 끝없이 나열되어 무엇부터 해야 할지 결정 장애 유발.
- **FlowDo 솔루션:** 오늘 화면에는 **최대 3개(확장 시 5개)**의 핵심 태스크만 크고 명확하게 노출. 나머지는 보관함(Inbox)에 조용히 대기시켜 인지적 압박감 원천 차단.

### ③ 죄책감 없는 하루 마감 (Guilt-Free Sunset Review)
- **기존 문제:** 끝내지 못한 할 일이 빨간색 '연체' 딱지로 누적되어 앱을 켜기 두렵게 만듦.
- **FlowDo 솔루션:** 저녁 또는 하루 마무리 시점에 "오늘도 수고하셨어요!" 긍정적 회고 제공. 못 다한 일은 질책 없이 `"내일로 넘기기"` 또는 `"보관함에 보관"`으로 분기하여 **매일 아침 깨끗한 도화지(Clean Slate)** 상태를 보장.

### ④ 0ms 체감 마이크로 인터랙션 (Tactile Micro-interactions)
- **기존 문제:** 체크박스 클릭 후 무미건조한 반응으로 성취감 부재.
- **FlowDo 솔루션:** 완료 시 시각적 체크 애니메이션, 가벼운 파티클 효과, 사운드/햅틱 연동으로 뇌에 즉각적인 도파민(성취 보상) 제공.

## 3. 핵심 기능 명세 (Core Feature Specifications)

### 3.1 초간편 태스크 입력 (Task Input)
- **단일 입력 바 (Omni-input):**
  - 메인 화면 상/하단에 고정된 텍스트 필드.
  - 마우스 클릭 없이도 단축키(`/` 또는 `N`)로 즉시 인풋 포커스.
- **스마트 프리픽스 파싱:**
  - `!` 프리픽스 입력 시 (예: `!고객 설문 정리`) ➔ 오늘의 Focus 태스크로 즉시 배치.
  - 프리픽스 미입력 시 ➔ 현재 Focus 슬롯(최대 3개)이 비어있으면 Focus로, 꽉 찼으면 Inbox로 자동 스마트 분기.
  - `Enter` 키로 즉시 등록, `Esc` 키로 취소/블러.

### 3.2 오늘의 Focus 모드 (Rule of 3 View)
- 메인 영역에 오늘 끝내야 할 태스크를 최대 3개까지만 카드/리스트 형태로 강조 표시.
- 진행 상황 프로그레스 바: `완료 개수 / 전체 집중 목표` (예: 2/3 완료, 67%).
- 모든 집중 태스크 완료 시 기분 좋은 축하 배너 및 메시지 표시 ("오늘의 핵심 목표를 모두 달성했습니다! 🎉").

### 3.3 보관함 / 백로그 (Inbox & Someday Drawer)
- 오늘 당장 하지 않을 생각이나 메모는 하단 슬라이드 시트(Drawer) 형태의 '보관함(Inbox)'에 보관.
- 보관함 내 태스크를 클릭 한 번으로 '오늘의 집중' 슬롯으로 승격(Promote).
- 불필요해진 태스크의 빠른 삭제 및 아카이빙 지원.

### 3.4 제스처 및 액션 (Micro-interactions)
- **완료 체크:** 클릭/탭 시 부드러운 취소선 드로잉, 텍스트 흐림 효과, 0.2초 축하 파티클.
- **태스크 인라인 수정:** 더블 클릭 또는 편집 버튼 클릭 시 인라인 에디팅 모드 진입.
- **순서 변경:** 드래그 앤 드롭(DnD) 또는 위/아래 이동 버튼으로 직관적 우선순위 변경.

### 3.5 하루 마감 회고 (Sunset Review Modal)
- 저녁 시간대(예: 18:00 이후) 또는 사용자가 '오늘 마무리' 버튼을 누르면 활성화.
- 오늘 달성한 태스크를 돌아보며 성취감 고취.
- 미완료 태스크를 처리하는 간결한 2지 선다:
  1. `내일 Focus로 예약하기`
  2. `보관함(Inbox)으로 보내기`
- 처리 완료 후 오늘 하루를 기분 좋게 닫는 마감 멘트 전달.

### 3.6 오프라인 우선 로컬 영속화 (Offline-First Storage)
- 로그인이나 서버 통신 없이 `localStorage` 기반 즉각 저장.
- 네트워크가 끊긴 오프라인 환경에서도 100% 정상 작동.
- 데이터 내보내기/가져오기(JSON) 지원으로 기기 간 마이그레이션 가능.

## 5. 데이터 구조 (Data Structure & Schema)

### 5.1 태스크 엔티티 (`Todo`)

```typescript
export type TodoStatus = 'today' | 'inbox' | 'completed' | 'archived';
export type Priority = 'high' | 'normal';

export interface Todo {
  id: string;               // 고유 식별자 (crypto.randomUUID())
  title: string;            // 할 일 제목 (자연어 원문)
  status: TodoStatus;       // 태스크 현재 상태
  priority: Priority;       // 우선순위 ('high'인 경우 Focus 자동 승격)
  order: number;            // 노출 정렬 순서 (0, 1, 2...)
  completedAt?: string;     // 완료 일시 (ISO 8601 string)
  createdAt: string;        // 생성 일시 (ISO 8601 string)
  updatedAt: string;        // 최근 수정 일시 (ISO 8601 string)
}
```

### 5.2 일일 회고 로그 엔티티 (`SunsetLog`)

```typescript
export interface SunsetLog {
  id: string;               // 고유 식별자
  date: string;             // 기록 날짜 (YYYY-MM-DD)
  completedCount: number;   // 완료 태스크 수
  totalFocusCount: number;  // 당일 Focus 태스크 총수
  reviewedAt: string;       // 회고 완료 시각 (ISO 8601)
}
```

### 5.3 사용자 설정 엔티티 (`UserSettings`)

```typescript
export interface UserSettings {
  maxFocusTasks: number;    // 최대 집중 태스크 개수 (기본값: 3, 최대: 5)
  soundEnabled: boolean;    // 완료 사운드 효과 사용 여부 (기본값: true)
  theme: 'system' | 'light' | 'dark'; // UI 테마
}
```
