# NBA Game Night Log UX 및 화면 설계

## 핵심 사용자 흐름

```text
오늘 또는 최근 NBA 경기 확인
  → 실제 경기·선수 기록 확인
  → 집관 또는 직관
  → 사진·티켓·감상으로 일기 작성
  → 아카이브에서 추억과 통계 확인
```

## 화면 구성

### 홈: Today’s NBA

- 인사 문구와 이번 시즌 총 관람 횟수
- 오늘 또는 최근 경기 카드: 팀, 스코어, 경기 상태, 날짜
- 관심 선수 카드: 득점·리바운드·어시스트 등 핵심 기록
- 최근 관람 일기 1~2개
- `관람 일기 쓰기` 주요 CTA

### 관람 일기 작성

- 경기 기본 정보: 날짜, 응원 팀, 상대 팀, 스코어, 결과
- 관람 정보: 관람 방식, 장소, 좌석(직관 시 선택)
- 감상 정보: 오늘의 최애 선수, 별점, 감정 이모지, 한 줄 감상
- 첨부 영역: 직접 찍은 사진 최대 3장, 선택적 티켓 최대 1장
- 티켓 개인정보 보호 안내와 저장 버튼

### 아카이브

- 총 관람 횟수와 관람 승률 요약 카드
- 월별 필터
- 사진, 경기 결과, 감상 첫 문장을 포함한 일기 카드 목록
- 카드를 누르면 일기 상세로 이동

### 일기 상세

- 경기 정보, 점수, 관람 방식, 별점, 감상 전문
- 업로드한 사진 갤러리와 선택적 티켓 이미지
- 수정과 삭제 액션

## UX 원칙

- 한 화면에서 사용자가 해야 할 가장 중요한 행동은 하나만 강조한다.
- 기록 작성은 1~2분 안에 끝날 수 있도록 필수 입력을 최소화한다.
- 빈 아카이브에서는 첫 기록 작성을 유도하는 안내와 CTA를 보여준다.
- 사진이 없더라도 텍스트만으로 일기를 저장할 수 있게 한다.
- 이미지 저장 실패, localStorage 용량 초과, 필수값 누락은 이유와 해결 방법을 명확히 안내한다.

## 시각 방향

- 스포츠 뉴스 앱보다 개인 스크랩북과 게임 카드의 질감을 우선한다.
- 다크 네이비를 바탕으로 코트 오렌지 또는 응원 팀 색을 포인트로 사용한다.
- 일기 카드에는 경기 날짜, 팀, 스코어, 승패, 한 줄 감상을 우선 배치하고 사진은 기억을 강화하는 요소로 사용한다.
