# 📋 FlowDo (심플 투두리스트) 제품 기획안

> **슬로건**: "생각은 덜고, 실행은 빠르게 — 1초 만에 적고 3개에 집중하는 미니멀 투두"

---

## 1. 기획 배경 및 문제 정의 (Problem Statement)
- **과도한 메타데이터의 피로감**: 기존 투두 앱(Notion, Todoist 등)은 카테고리, 태그, 마감일 등 입력 단계가 많아 할 일을 기록하는 행위 자체가 부담이 됨.
- **끝없는 목록과 심리적 부채**: 수십 개의 미완료 작업이 쌓여 성취감보다 죄책감과 번아웃을 유발.
- **실행 포커스 부재**: 오늘 당장 끝내야 할 가장 중요한 작업(Top Priority)이 시각적으로 분리되지 않음.

---

## 2. 핵심 가치 및 원칙 (Core Principles)
1. **Zero-Friction (마찰 없는 빠른 입력)**: 앱 실행 즉시 1초 만에 입력하고 엔터로 등록 완료.
2. **Rule of 3 (선택과 집중)**: 하루에 진정한 성취감을 주는 일은 최대 3개면 충분하다는 원칙 적용.
3. **Sensory Reward (감각적 보상)**: 체크 완료 시 부드러운 애니메이션 및 미니 컨페티 효과로 긍정적 도파민 부여.
4. **Local-First & Privacy**: 로그인 없이 브라우저 로컬 스토리지(`localStorage`)에 안전하고 빠르게 저장.

---

## 3. 주요 기능 명세 (Feature Specifications)

### 3.1 빠른 작업 등록 (Instant Add)
- 앱 로드 시 입력 필드 자동 포커스.
- `Enter` 키로 즉시 등록, `Esc` 키로 입력 취소.

### 3.2 '오늘의 Top 3' 포커스 핀 (Focus Pinning)
- 상단 **Today's Top 3** 구역에 최대 3개 작업 고정.
- 3개가 초과되는 할 일은 하단 **Inbox (대기 목록)** 구역으로 자동 분류.
- 클릭 또는 드래그 앤 드롭으로 Top 3와 대기 목록 간 이동 가능.

### 3.3 마이크로 인터랙션 & 보상 (Micro-Interactions)
- 완료 체크 시 스트라이크스루 애니메이션 및 파티클(Confetti) 효과.
- 완료된 작업은 하단 **Done (완료 목록)** 구역으로 이동 (접기/펼치기 지원).
- 인라인 더블클릭으로 텍스트 즉시 수정.

### 3.4 젠틀 리셋 (Gentle Daily Reset)
- 날짜가 바뀌었을 때 미완료된 할 일을 빨간 경고창 대신 "오늘로 가져오기" 또는 "보관함으로 보내기"로 유연하게 처리.

## 5. 차별화 포인트 요약

| 항목 | 일반 투두 앱 | **FlowDo** |
| :--- | :--- | :--- |
| **인지 부하** | 수십 개 태스크가 한 번에 노출 | **Top 3 집중 구역**으로 뇌의 피로 최소화 |
| **입력 경험** | 카테고리/날짜 등 복잡한 옵션 | 단일 인풋 + `Enter`로 **1초 만에 완료** |
| **완료 경험** | 단순 체크 박스 해제 | **경쾌한 파티클 및 햅틱 감각 피드백** |
| **접근성** | 회원가입/로그인 강제 | **Local-First (No-Login)** 브라우저 즉시 사용 |

## 6. 개발 단계별 로드맵 (Milestones)

- **Phase 1 (MVP)**: 단일 입력창, 기본 CRUD, LocalStorage 저장, 미니멀 UI
- **Phase 2 (UX Polish)**: Today's Top 3 구역 분리, 완료 시 Confetti 애니메이션, 다크 모드
- **Phase 3 (Expansion)**: PWA(홈 화면 추가), 키보드 숏컷, JSON 데이터 내보내기/가져오기
