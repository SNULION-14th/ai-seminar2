# NBA Game Night Log 서비스 기획

## 한 줄 소개

**NBA Game Night Log**는 NBA 팬이 집에서 본 경기를 실제 NBA 경기·선수 데이터와 사진·감상으로 기록해 나만의 시즌 아카이브를 만드는 서비스다.

## 문제와 사용자

NBA 팬의 집관 기억은 사진첩, SNS, 메모장, 경기 기록 사이트에 흩어진다. 시간이 지나면 특정 경기의 감상, 누구와 봤는지, 어떤 선수가 인상적이었는지 다시 찾기 어렵다. 경기 정보와 선수 기록도 따로 찾아야 하므로 개인적인 관람 기억과 경기 맥락이 연결되지 않는다.

주요 사용자는 NBA를 집에서 시청하는 팬, 좋아하는 팀과 선수를 따라가는 라이트 팬, 시즌 동안의 관람 기록을 한곳에 남기고 싶은 팬이다.

### 핵심 사용자 경험

경기 직후 사용자가 1~3분 안에 기록을 남기는 흐름을 목표로 한다.

1. 오늘 또는 최근에 본 경기를 고른다.
2. 실제 경기 결과와 핵심 선수 기록을 자동으로 확인한다.
3. 평점, 감정, 사진, 한 줄 감상을 남긴다.
4. 기록은 시즌 캘린더와 개인 팬 통계에 즉시 쌓인다.
5. 시즌이 끝나면 가장 열광했던 경기와 선수를 되돌아본다.

## 핵심 가치

- **경기 선택:** 실제 NBA 점수·일정·주요 선수 기록을 보고 시청한 경기를 고른다.
- **경기 후:** 집관 사진·한 줄 감상을 하나의 일기 카드에 남긴다.
- **시즌 전체:** 쌓인 기록으로 나만의 관람 횟수와 응원 팀 승률, 기억을 되돌아본다.

NBA 기록 서비스 자체를 대체하지 않는다. NBA Game Night Log는 실제 경기 데이터와 한 명의 팬이 경험한 관람 기억을 연결하는 개인 아카이브에 집중한다.

## MVP 기능

### 1. Today’s NBA

- 오늘 또는 최근 NBA 경기를 카드로 보여준다.
- NBA Stats MCP에서 가져온 경기 상태, 스코어, 팀, 일정 정보를 보여준다.
- 사용자가 관람한 경기를 선택하면 스코어와 승패를 일기에 자동 입력한다.
- 관심 팀의 다음 경기 또는 최근 경기로 빠르게 이동할 수 있다.

### 2. 선수 관전 포인트

- NBA Player Stats MCP에서 가져온 관심 선수의 시즌·커리어·고급 기록을 보여준다.
- 사용자는 오늘의 최애 선수를 고르고, 해당 선수의 간단한 기록을 일기에 함께 남긴다.
- 복잡한 지표는 MVP에서 모두 노출하지 않고, 득점·리바운드·어시스트 같은 핵심 기록을 우선한다.

### 3. 관람 일기 작성

- 선택한 경기의 날짜, 응원 팀, 상대 팀, 최종 스코어, 경기 결과를 자동 입력하거나 수정한다.
- 관람 방식(집관, 직관, 스포츠 펍·팝업), 오늘의 최애 선수, 만족도, 한 줄 감상을 기록한다.
- 사용자가 직접 찍은 집관 사진은 최대 3장, 티켓 이미지는 선택적으로 1장까지 첨부한다.

### 4. 나의 Game Night 아카이브

- 저장한 관람 일기를 최신순 카드로 보여준다.
- 월별 필터를 제공한다.
- 총 관람 횟수와 응원 팀 경기의 관람 승률을 보여준다.

## MVP 제외 범위

- 실제 티켓 예매·결제와 경기 영상 재생
- 로그인, 계정 동기화, 서버 데이터베이스
- 실시간 데이터 동기화와 알림
- 팬 간 소셜 기능과 일기 공유
- 지도 API 기반 길찾기

## 차별화 포인트

### 실제 NBA 데이터 위의 개인 기억

일반 스포츠 서비스가 결과와 순위를, 일반 메모 앱이 감상만 다룬다면 이 서비스는 실제 경기·선수 기록 위에 사진, 관람 환경, 감정을 쌓는다. 사용자는 경기의 객관적 맥락과 그날의 개인적 기억을 한 장의 기록으로 다시 볼 수 있다.

### 나만의 관람 기준 통계

리그 전체 통계 대신 사용자가 시청한 경기만을 기준으로 응원 팀 승률, 자주 본 선수, 최고 평점 경기, 감정 분포를 보여준다. 같은 NBA 시즌이라도 사용자마다 다른 개인 시즌 이야기가 만들어진다.

### 축적되는 시즌 스크랩북

가벼운 한 경기 로그가 쌓여 한 시즌의 팬 다큐멘터리가 된다. 이 축적 가치가 경기 직후 재방문과 시즌 말 회고의 이유가 된다.

## 성공 지표

- 첫 관람 일기 작성 완료율
- 사용자당 월간 저장 경기 수
- 경기 종료 후 24시간 안에 작성된 기록 비율
- 사진 또는 메모가 포함된 일기 비율
- 주간·월간·시즌 리캡 조회율
- 4주 이상 연속으로 기록한 사용자 비율

## 확장 아이디어

- 친구와 함께 본 경기 태그
- 응원 팀·선수별 관람 통계
- 관심 팀·선수 기반 다음 경기 알림
- 시즌 스크랩북 공유
