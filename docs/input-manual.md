# 카드뉴스 입력 안내

이 도구는 Figma 레퍼런스와 전달할 내용을 모아 로컬 브리프를 만들고, AI 에이전트가 작성한 배치를 검증해 Figma로 전달합니다. 웹앱에서 AI API를 직접 호출하지 않습니다.

## 입력 항목

| 입력 | 작성할 내용 |
| --- | --- |
| 브랜드 자료 | 브랜드 소개, 사용하는 표현, 피할 표현, 확인된 사실 |
| 전달 내용 | 카드뉴스로 알릴 내용과 독자가 취할 행동 |
| 개요 | 카드별 순서와 핵심 메시지. 생략하면 에이전트가 구성합니다 |
| 타겟 | 독자의 관심사와 사전 지식 |
| 어투 | 친근한·차분한·전문적인 중 선택 |
| 꼭 지킬 것 | 이번 작업에 반드시 적용할 조건 |
| 장수 | 표지와 마무리를 포함한 전체 카드 수 |
| 레퍼런스 | Figma 플러그인에서 읽은 디자인 JSON |

예를 들어 개발 동아리 행사 안내라면 전달 내용에 행사 일정·대상·신청 방법을, 꼭 지킬 것에는 “신청 마감일을 마지막 카드에 표시”를 적습니다. 제공하지 않은 일정·성과·가격은 임의로 추가하지 않습니다.

## 정보가 충돌할 때

우선순위는 꼭 지킬 것 → 브랜드 자료 → 전달 내용과 개요 → 타겟·목적·어투 → 레퍼런스입니다. 입력 조건은 내용과 표현의 기준이며, 넘침·겹침 등 배치 검증은 별도로 통과해야 합니다.

## 레퍼런스 적용 방식

| 방식 | 유지하는 것 | 재구성하는 것 |
| --- | --- | --- |
| 레퍼런스 유지 | 모든 장의 배치와 구성 흐름 | 새 내용에 맞춘 문구·사진·분량 |
| 본문 재구성 | 첫 장과 마지막 장의 배치 | 중간 장의 정보 구조와 배치 |
| 전체 재구성 | 색·글꼴·판형 | 모든 장의 배치와 구성 |

프레임 배열 순서가 카드 순서입니다. 요청 장수가 달라도 첫 장은 첫 프레임, 마지막 장은 마지막 프레임을 참고합니다. 재구성하는 장은 원본 여백이나 사진 면적을 그대로 따를 필요가 없습니다. 재구성할 장마다 정보 그룹, 사진의 유무와 비중, 글자 정렬과 강조 위치 중 최소 두 가지를 새로 결정합니다.

디자인 기준은 레퍼런스의 배경색, 텍스트 위치·크기·서식, 사진 칸과 도형에서 추출합니다. 플러그인은 임시 텍스트 복제본에서 실제 폰트로 글자 수용량을 측정하고 원본을 보존합니다. 혼합 서식 등 측정이 어려운 경우에는 원문 분량을 참고하고 안내를 남깁니다.

## 생성과 검증

1. 웹앱에서 입력과 레퍼런스를 채우고 **브리프 저장**을 누릅니다.
2. AI 에이전트에게 `brief/latest.json`을 읽고 카드뉴스를 만들도록 요청합니다.
3. 에이전트는 `validateLayout(deck, extractTokens(manifest), input.templateMode)`로 검사하고 결과를 `brief/layout.json`에 저장합니다.
4. 웹앱에서 **결과 불러오기**로 확인하고 Figma용 JSON을 복사합니다.
5. Figma 플러그인의 **카드 만들기**에 붙여넣고 생성합니다.

저장할 때마다 새로운 `briefId`와 레퍼런스 스냅샷의 `templateHash`가 만들어집니다. 결과에는 해당 브리프의 두 값을 그대로 넣으며 장수·순서도 일치해야 합니다.

화면의 입력이 달라도 저장된 결과를 조회할 수 있습니다. 차이는 화면에 안내하며 미리보기·검증·복사는 결과를 만들 때의 레퍼런스와 적용 방식을 사용합니다. 수정한 입력으로 새 결과를 만들려면 브리프를 다시 저장합니다.

넘침·겹침·화면 밖 배치·대비 검사는 모든 방식에 적용합니다. 실제 줄바꿈과 사진 위 가독성은 Figma에서 최종 확인합니다.

## 사진과 저장 위치

사진은 선택 사항입니다. 파일 이름으로 카드와 사진 칸을 지정합니다. `photo-1.jpg`는 첫 카드의 첫 사진, `photo-3-2.jpg`는 세 번째 카드의 두 번째 사진입니다. 사진을 넣지 않으면 Figma에 회색 자리로 생성됩니다.

입력은 브라우저 localStorage에 저장되며, 브리프와 결과는 로컬 `brief/`에 저장됩니다. 브랜드 자료나 인증 정보를 소스 저장소에 커밋하지 않습니다. 설치와 전체 사용 순서는 [README](../README.md)를 참고하세요.
