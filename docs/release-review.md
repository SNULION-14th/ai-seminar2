# 공개 전 검토 — 2026-09-23

## 보완한 항목

- 수작업 레퍼런스는 중복 이름과 작은 누락을 허용한다. 보완 가능한 숫자·색·글자 예산·요약은 복구하고 사용할 수 없는 레이어만 안내 후 제외한다. 생성된 배치와 잘못된 브라우저 저장값의 검사는 유지한다.
- 반투명 면을 실제 배경과 합성해 대비를 검사하고 글자를 뒤에서 가리는 면·사진을 찾는다. 사진의 실제 밝기는 별도 확인이 필요하다.
- Figma에서 실제 글꼴로 배치한 텍스트의 높이·경계·겹침을 확인한다. 실패한 생성의 노드를 정리하고 작업 중복 실행을 막는다.
- 늦은 Markdown 파일 읽기가 새 입력을 덮지 않는다. 읽는 동안 브리프 저장을 막고 복사가 실패하면 직접 복사 방법을 안내한다.
- 로컬 서버에서 외부 출처의 요청과 비공개 파일의 직접 URL 접근을 차단한다. 요청 크기·전송 시간도 제한한다.
- `npm run check`, Node 버전 안내, 공개 제외 목록, GitHub Actions와 문서 색인을 추가했다.

| 검사 | 결과 |

| 기존 4장 결과 | 브리프 대응·레퍼런스·배치 검사 통과, 오류·경고 0건 |
| 불완전한 레퍼런스 | 중복 이름·누락 정보 보완, 반복 읽기와 저장·결과 조회의 해시 안정성 통과 |
| 중첩 프레임 선택 | 부모가 프레임·그룹·섹션이어도 읽기 허용, 8개·2개 선택 안내와 읽기 버튼 상태, 원본 보존 검증 통과 |
| 공개 후보 파일 | 비밀키 패턴·개인 절대경로 없음; 환경변수·브리프·렌더·개인 설정·빌드 결과 제외 확인 |

로컬 검사는 macOS / Node 26.9.0에서 실행했다. CI는 `.nvmrc`의 Node 24를 사용하도록 구성했으며 원격에서는 아직 실행하지 않았다. 의존성 감사는 조회 시점의 알려진 취약점만 확인한다.

## 남은 확인

- 실제 Figma에서 현재 글꼴의 줄바꿈·사진·PNG 내보내기를 확인한다. Figma 동작 테스트는 API 모형을 사용했다.
- PR에 실제 사용한 MCP 2종과 사용 목적·결과 링크를 기록한다. 개발 플러그인 자체는 MCP 사용 기록이 아니다.
- Vite가 차기 기본 설정 로더의 확장자 요구사항을 안내한다. 현재 기본 로더와 빌드는 정상 통과했다.

반복 검증 기준은 [acceptance.md](acceptance.md)를 따른다.
