## Implementation

- Match the Figma layout, spacing, typography, and visual hierarchy.
- Reuse existing design patterns before inventing new ones.
- Keep UI consistent across pages.
- Support responsive layouts where required by the design.
- Use provided assets when available.
- Do not invent major UI states or interactions not supported by the specs.

## Verification

Verify important UI states with Playwright after implementation.
