# NBA Game Night Log MCP 운영 규칙

## 과제에서 사용할 MCP

| MCP | 목적 | 산출물 또는 확인 방법 |
| --- | --- | --- |
| NBA Stats MCP | NBA 경기 일정, 스코어, 팀 순위·로스터 등 경기 맥락을 조회 | Today’s NBA 경기 카드와 자동 입력된 경기 정보 |
| NBA Player Stats MCP | 관심 선수의 시즌·커리어·고급 기록을 조회 | 선수 관전 포인트 카드와 일기 속 최애 선수 기록 |
| Figma MCP | 스크랩북·게임 카드 감성의 화면 디자인을 분석하고 React UI 구현에 반영 | Figma 프레임 링크와 구현된 화면 |
| GitHub MCP | 작업 브랜치 관리, 커밋·푸시, main 대상 PR 작성 | 원격 브랜치와 PR |

## NBA 데이터 MCP 사용 원칙

- NBA Stats MCP가 연결되기 전에는 샘플 경기 데이터로 화면 상태를 구현할 수 있다.
- 연결 후에는 오늘 또는 최근 경기의 팀, 스코어, 일정 정보를 조회한다.
- NBA Player Stats MCP는 일기에 선택된 관심 선수의 기록을 조회하는 데 사용한다.
- 서로 다른 MCP의 원본 응답을 그대로 UI에 노출하지 않고, `src/types/`의 공통 타입으로 변환한다.

| 데이터 | UI 사용 위치 |
| --- | --- |
| 경기 일정·상태·스코어 | Today’s NBA와 일기 작성 폼 |
| 팀 순위·로스터 | 관심 팀 정보와 경기 선택 보조 |
| 선수 득점·리바운드·어시스트 | 선수 관전 포인트와 일기 상세 |
| 선수 시즌·커리어 기록 | 선수 상세 카드 |

## PR 작성 규칙

PR 본문에는 아래 내용을 반드시 포함한다.

1. NBA Game Night Log의 사용자 문제와 구현 기능 요약
2. NBA Stats MCP를 경기 데이터에 사용한 방식
3. NBA Player Stats MCP를 선수 데이터에 사용한 방식
4. Figma MCP를 UI 구현에 사용한 방식과 Figma 프레임 링크
5. GitHub MCP를 브랜치·커밋·PR에 사용한 방식
6. 확인한 기능과 알려진 제한 사항
