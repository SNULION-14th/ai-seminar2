# NBA Game Night Log 도메인 규칙

## 관람 일기 데이터

각 일기는 아래 정보를 가진다.

| 필드 | 설명 | 필수 |
| --- | --- | --- |
| id | 브라우저 내 고유 식별자 | 예 |
| gameDate | 관람 날짜 | 예 |
| favoriteTeam | 응원 팀 | 예 |
| opponentTeam | 상대 팀 | 예 |
| homeScore / awayScore | 최종 스코어 | 아니오 |
| result | WIN, LOSS, DRAW, UPCOMING 중 하나 | 예 |
| viewingMode | HOME, ARENA, PUB, POPUP 중 하나 | 예 |
| venue | 관람 장소 또는 경기장 | 아니오 |
| seat | 좌석 정보, ARENA일 때만 사용 | 아니오 |
| favoritePlayer | 오늘의 최애 선수 | 아니오 |
| rating | 1~5점 | 예 |
| mood | 감정 이모지 또는 라벨 | 아니오 |
| note | 한 줄 감상 또는 후기 | 아니오 |
| photos | 직접 촬영한 이미지 data URL 배열, 최대 3개 | 아니오 |
| ticketImage | 실제 직관·팝업 티켓 이미지 data URL, 최대 1개 | 아니오 |
| createdAt / updatedAt | 생성·수정 시각 | 예 |

## 저장 규칙

- MVP에서는 `localStorage`의 단일 키에 일기 배열을 저장한다.
- 이미지 파일은 저장 전에 리사이즈·압축하거나 파일 크기 제한을 둔다.
- 저장 공간이 부족하면 기존 기록을 삭제하지 않고, 이미지 수를 줄이거나 더 작은 파일을 선택하도록 안내한다.
- 이미지 업로드 실패는 텍스트 기록 저장 자체를 막지 않는다.

## 티켓 및 사진 규칙

- 티켓 업로드 영역에는 QR 코드, 바코드, 예매 번호 같은 정보 노출 주의 문구를 항상 표시한다.
- 방송 화면 캡처·경기 영상 대신 사용자가 직접 촬영한 집관·직관 사진만 업로드하도록 안내한다.
- 앱은 과제 시연 목적의 개인 기록 도구이며, 업로드한 이미지를 외부에 공개하거나 공유하지 않는다.
- 사용자가 선택한 이미지는 현재 브라우저에만 저장된다.

## 통계 규칙

- 총 관람 횟수는 `UPCOMING`이 아닌 저장된 모든 일기 수다.
- 관람 승률은 결과가 `WIN` 또는 `LOSS`인 일기만 사용해 계산한다.
- 승률 = WIN 수 / (WIN 수 + LOSS 수) × 100이며, 대상 경기가 없으면 `-`로 표시한다.
