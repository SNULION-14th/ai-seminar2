# 📋 [Product Concept] "FocusFlow" : 마찰 없는 미니멀 Todo List

> **핵심 가치**: *"Zero Friction, Instant Delight"*  
> 복잡한 설정과 분류로 인한 피로를 없애고, **3초 안에 등록하고 기분 좋게 완료**하는 경험을 제공합니다.

---

## 1. 프로젝트 개요 & 타깃 페르소나

* **기획 배경**: 기존 생산성 앱(노션, 지라 등)은 너무 무겁고 설정할 것이 많아, 정작 할 일을 적기도 전에 피로감을 줍니다.
* **타깃 사용자**: 
  * "오늘 당장 끝내야 할 일" 몇 가지만 빠르게 적고 지우고 싶은 사람
  * 키보드에서 손을 떼지 않고 빠른 입력과 처리를 원하는 개발자/학생/직장인
* **제품 목표**: 앱 진입부터 할 일 등록까지 **클릭 0회, 3초 컷** 달성

---

## 2. 핵심 기능 (UX 중심)

| 영역 | 기능명 | UX 디테일 |
| :--- | :--- | :--- |
| **입력 (Create)** | **즉시 입력 (Zero-Click Focus)** | • 앱 진입 시 입력창에 커서 자동 포커싱<br>• `Enter` 한 번으로 저장 후 즉시 다음 할 일 입력 모드 유지 |
| **관리 (Read/Update)** | **원터치 완료 & 인라인 수정** | • 체크박스 클릭 즉시 부드러운 취소선 + 투명도 전환 애니메이션<br>• 텍스트 더블클릭 시 바로 수정 모드 진입 |
| **정렬 (Organize)** | **직관적 우선순위 재배치** | • 드래그 앤 드롭(Drag & Drop)으로 순서 변경<br>• 중요 할 일 핀(Pin/별표) 기능으로 상단 고정 |
| **성취 (Progress)** | **실시간 달성률 피드백** | • 상단 프로그레스 바(`3 / 5 완료 (60%)`)<br>• 전부 완료 시 축하 애니메이션(컨페티 효과) |
| **저장 (Persistence)** | **로그인 프리 (Instant Start)** | • 회원가입/로그인 없이 `LocalStorage`에 즉시 자동 저장<br>• 새로고침/재방문 시 데이터 100% 보존 |

## 3. 화면 구성 (Single-Page Dashboard)

복잡한 페이지 이동 없이 **단일 화면(Single View)** 안에서 모든 작업이 완결됩니다.

```text
┌────────────────────────────────────────────────────────┐
│  ☀️ 2026. 09. 19 (토)          [ 60% 달성 ] 3/5 완료  │
│  [=======================>             ] (Progress)    │
├────────────────────────────────────────────────────────┤
│  [+] 오늘 집중해야 할 일을 입력하세요... (Press Enter)  │
├────────────────────────────────────────────────────────┤
│  [ ] ⭐️ 1. AI 세미나 2주차 과제 제출하기           [x] │
│  [ ]    2. 장보기 (우유, 계란)                     [x] │
│  [v] ~~3. 백엔드 API 문서 검토~~                  [x] │
│  [v] ~~4. 러닝 30분 달리기~~                       [x] │
├────────────────────────────────────────────────────────┤
│  남은 할 일: 2개  |  [전체] [진행 중] [완료]  |  [완료 정리]│
└────────────────────────────────────────────────────────┘
```

* **헤더 (Header)**: 오늘의 날짜, 완료율 프로그레스 바 (게이미피케이션 요소)
* **입력부 (Input Field)**: 군더더기 없는 입력창 + 중요 표시(별표) 토글
* **리스트 (List Area)**: 마우스 호버 시에만 나타나는 삭제/수정 버튼 (시각적 노이즈 최소화)
* **풋터 (Action Bar)**: 잔여 개수 카운터, 필터 탭 (전체/진행/완료), 완료된 항목 일괄 정리 버튼

## 4. FocusFlow만의 차별화 포인트 (UX Differentiators)

1. **Keyboard-First Experience (키보드 친화적 설계)**
   * 마우스 없이도 `Enter`(등록), `Esc`(취소), `Space`(체크), `방향키`(이동) 등 키보드만으로 모든 조작이 가능하여 타이핑 흐름이 끊기지 않습니다.
2. **Micro-Delight (도파민을 자극하는 완료 인터랙션)**
   * 체크 시 미세한 햅틱/효과음(옵션)과 함께 쫀득한 체크 애니메이션이 적용됩니다.
   * 오늘의 모든 할 일을 완료했을 때 가벼운 컨페티(꽃가루) 효과와 격려 메시지를 띄워 성취감을 극대화합니다.
3. **Daily Focus Mode (선택과 집중)**
   * 할 일이 7개 이상 쌓이면 "오늘 정말 다 할 수 있나요? 핵심 3가지에 집중해보세요"라는 넛지(Nudge) 안내를 제공해 심리적 부담감을 낮춥니다.
4. **다크 모드 & 미니멀 테마 자동 지원**
   * OS 설정에 따른 부드러운 다크/라이트 모드 자동 감지.
