# 기능 스펙 — 트래킹 (Track)

> Status: **Approved** (2026-09-24) · 마일스톤: M2 · 관련: [domain-data.md](domain-data.md), [design-system.md](design-system.md)

## 1. 목적

달리는 중에는 **"지금 어디쯤이고, 다음 도장까지 얼마나 남았나"** 만 한눈에 보이면 된다. 조작은 최소화하고 숫자는 크게 보여 준다.

## 2. 사용자 스토리

- 라이더로서, 시작 버튼 하나로 오늘 라이딩 기록을 시작하고 싶다.
- 라이더로서, 다음 인증센터까지 남은 km와 오늘 계획 대비 진행 상황을 보고 싶다.
- 라이더로서, 인증센터에 도착하면 도장을 찍어 기록하고 싶다.
- 개발자/발표자로서, 실제로 자전거를 타지 않고도 트래킹을 재현하고 싶다(시뮬레이션 모드).

## 3. 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| TRK-01 | 라이딩 상태 머신: `idle → riding ⇄ paused → finished`. 상태는 매 전이마다 로컬에 저장하고, 새로고침/앱 재진입 시 `riding` 상태를 복구한다 | P0 |
| TRK-02 | 위치 수집: `navigator.geolocation.watchPosition`(high accuracy). 정확도(`accuracy`)가 50m를 넘는 점은 버리고, 직전 점과 10m 미만이면 기록하지 않는다(샘플링) | P0 |
| TRK-03 | 실시간 지표: 현재 속도, 오늘 이동 거리, 이동 시간(정지 제외), 평균 속도 | P0 |
| TRK-04 | 경로 투영: `snapToRoute`로 누적 km를 계산하고, 전체 진행률(DS-04)과 다음 인증센터까지 남은 거리를 보여 준다 | P0 |
| TRK-05 | 경로 이탈 알림: 300m 넘게 벗어난 상태가 30초 이상 이어지면 비침습 배너를 띄운다 | P1 |
| TRK-06 | 도장: 인증센터 반경 150m에 들어오면 "도장 찍기" 시트를 자동으로 띄운다 → 사용자가 확인하면 DS-03 애니메이션과 함께 저장(`method: 'auto'`). 리스트에서 직접 찍기(`manual`)도 지원한다 | P0 |
| TRK-07 | 계획 연동: 활성 계획이 있으면 오늘의 DayPlan 목표 대비 "+12km 앞섬 / -8km 뒤처짐"을 보여 준다 | P1 |
| TRK-08 | 지도: 실제 지도 타일 위에 국토종주 경로(회색), 오늘 달린 궤적(강물색), 현재 위치(노을색 펄스), 인증센터 마커(찍음/안찍음 구분) | P0 |
| TRK-09 | 화면 켜짐 유지: Screen Wake Lock API 토글(지원 브라우저만) | P1 |
| TRK-10 | **시뮬레이션 모드**: 설정 또는 `?sim=1`로 켠다. 선택한 구간의 경로를 따라 가짜 위치를 재생하고 배속(1x, 10x, 60x)을 지원한다. 기록의 `source`는 `'simulated'`로 저장한다 | P0 |
| TRK-11 | 라이딩 종료 시 요약 시트: 거리, 시간, 찍은 도장, 한 줄 메모 입력 → 일지로 저장 | P0 |
| TRK-12 | 플랫폼 한계 고지: 화면이 꺼지거나 브라우저가 백그라운드로 가면 GPS가 멈출 수 있다는 안내를 첫 사용 시 1회 보여 준다. 복귀 시 끊긴 구간은 직선으로 잇지 않고 "기록 공백"으로 표시한다 | P0 |
| TRK-13 | 위치 권한 거부/미지원 시 안내하고 수동 도장 + 시뮬레이션으로 대체 흐름을 제공한다 | P0 |

## 5. 수용 기준

- [ ] 시뮬레이션 모드로 `saejae` 구간을 60x로 재생하면 수안보온천 → 이화령휴게소 → 문경불정역 → 상주 상풍교 순서대로 도장 시트가 뜬다
- [ ] 라이딩 중 새로고침하면 `riding` 상태, 누적 거리, 궤적이 복구된다
- [x] 정확도 100m짜리 가짜 점을 넣으면 궤적에 기록되지 않는다 (단위 테스트)
- [ ] 위치 권한을 거부하면 크래시 없이 대체 안내가 나온다
- [ ] 종료 후 요약 시트에서 저장한 일지가 기록 화면에 나타난다
- [ ] 390×844 뷰포트에서 핵심 숫자가 40px 이상이고 버튼이 56px 이상이다 (Playwright MCP로 측정)
