# 디자인 시스템 — "강을 따라 흐르는 한 줄"

> Status: **Implemented** (2026-09-24) · 관련: [cross-country-tour.md](cross-country-tour.md)

## 1. 콘셉트

633km 국토종주는 결국 **한 줄의 강줄기**다. 서해의 아라뱃길에서 시작해 한강, 남한강을 거쳐 새재의 능선을 넘고 낙동강을 따라 남해로 흘러간다. 모든 화면은 이 "한 줄"을 중심 모티프로 삼는다.

- **자연친화**: 한지, 이끼, 강물, 흙, 노을에서 뽑은 색. 둥근 모서리와 유기적 곡선을 쓰고 딱딱한 격자는 피한다.
- **인터랙티브**: 스크롤하고, 끌고, 찍는 동작에 화면이 물리적으로 반응한다. 단 모든 모션은 의미가 있어야 하고 `prefers-reduced-motion`을 존중한다.
- **개성**: 흔한 피트니스 앱(검정 배경 + 형광색)과 반대로 간다. 여행 수첩 + 수묵 지도 + 인증 도장의 감성.

## 2. 디자인 토큰 (초안)

CSS custom properties로 `src/styles/tokens.css`에 정의한다. 컴포넌트는 토큰만 참조하고 hex 값을 직접 쓰지 않는다.

### 색상

| 토큰 | 라이트 | 다크(밤 라이딩) | 용도 |
| --- | --- | --- | --- |
| `--c-paper` | `#F5F0E6` (한지) | `#141A17` | 배경 |
| `--c-ink` | `#2B2A26` (먹) | `#E8E4DA` | 본문 텍스트 |
| `--c-moss` | `#4F6B3A` (이끼) | `#8DB36B` | 주 액션, 완료 구간 |
| `--c-river` | `#2C767D` (강물) | `#5FB8BF` | 경로 라인, 링크 |
| `--c-earth` | `#A0784F` (흙) | `#C49A6C` | 고도, 오르막 |
| `--c-sunset` | `#E07A3F` (노을) | `#F09A5E` | 강조, 현재 위치, 도장 잉크 |
| `--c-mist` | `#DCE3DC` (물안개) | `#26302B` | 카드, 구분선 |

- 텍스트/배경 대비는 WCAG AA(4.5:1) 이상이어야 한다. 구현 시 검증한다.
- 라이트 모드에서 `--c-earth`, `--c-sunset`은 paper 위 대비가 4.5:1 미만이라 텍스트 색으로 쓰지 않는다(그래픽 전용). sunset 배경 위 글자는 `--c-on-sunset`(라이트 ink 4.81:1, 다크 paper 7.97:1)을 쓰고, 도장 여부처럼 의미 있는 상태는 색만으로 구분하지 않는다.
- 보조 텍스트는 `--c-ink-muted`(ink 74% + paper 혼합, paper 위 5.77:1, mist 위 5.01:1)를 쓴다. 그 밖의 파생 토큰(`--sky-*`, `--c-ridge-*`, `--c-water` 등)은 위 팔레트에서 `color-mix`로 만들고 `tokens.css`에만 둔다.
- **시간대 틴트**(트래킹 화면): 새벽/낮/노을/밤 4단계로 배경 그라데이션이 서서히 바뀐다. 기기 시계 기준.

### 타이포그래피

| 역할 | 폰트 | 비고 |
| --- | --- | --- |
| 제목/브랜드 | Gowun Batang (Google Fonts) | 붓글씨 느낌의 세리프로 여행 수첩 감성 |
| 본문/UI | Pretendard | 가독성 우선 |
| 숫자(거리·속도) | Pretendard `font-variant-numeric: tabular-nums` | 값이 바뀌어도 폭이 흔들리지 않게 |

### 형태

- 모서리: `--r-sm 8px` / `--r-md 16px` / `--r-lg 28px`. 카드는 한 모서리만 더 둥글게 하는 비대칭 조약돌 형태를 허용한다.
- 그림자: 딱딱한 드롭섀도 대신 넓게 퍼지는 부드러운 그림자 1종(`--shadow-soft`).
- 질감: 배경에 아주 옅은 종이 노이즈(SVG filter 또는 저용량 PNG, 5% 이하).

## 3. 시그니처 인터랙션

각 항목은 구현 여부를 수용 기준으로 검증한다.

| ID | 이름 | 설명 | 적용 화면 |
| --- | --- | --- | --- |
| DS-01 | **강줄기 스크롤** | 홈에서 스크롤하면 633km 경로가 SVG `stroke-dashoffset`으로 그려지고, 자전거 아이콘이 경로를 따라 이동한다. 구간(아라→한강→남한강→새재→낙동강)마다 배경 레이어(산 능선, 강)가 패럴랙스로 바뀐다 | 홈 |
| DS-02 | **능선 고도 프로필** | 고도 그래프를 겹겹의 산 능선 실루엣으로 표현한다. 드래그/터치하면 해당 지점의 거리·고도·가까운 인증센터를 툴팁으로 보여 준다 | 계획, 기록 |
| DS-03 | **도장 찍기** | 인증센터를 체크하면 도장이 위에서 "쿵" 찍히고(scale + 약간의 회전) 잉크가 번지는 애니메이션이 재생된다. 지원 기기에서는 짧은 진동(`navigator.vibrate`)을 준다 | 트래킹, 기록 |
| DS-04 | **흐르는 진행률** | 전체 진행률 바가 물결 SVG로 채워지고, 값이 바뀔 때 물결이 출렁인다 | 트래킹, 기록 |
| DS-05 | **시간대 하늘** | 트래킹 화면 배경이 현재 시각에 따라 새벽/낮/노을/밤 그라데이션으로 전환된다 | 트래킹 |
| DS-06 | **일정 조약돌 드래그** | 계획 화면에서 일자 경계(숙박 지점)를 조약돌 핸들로 끌어 앞뒤 인증센터로 옮길 수 있다 | 계획 |

## 4. 원칙 / 제약

- **모바일 우선**: 기준 뷰포트는 390×844. 데스크톱은 가운데 정렬 최대 폭 480px + 양옆 풍경 일러스트로 처리한다.
- **라이딩 중 가독성**: 트래킹 화면의 핵심 숫자(현재 속도, 남은 거리)는 최소 40px로 쓰고 장갑 낀 손으로도 누를 수 있게 터치 타깃을 56px 이상으로 한다.
- **모션 예산**: 한 화면에서 동시에 도는 연속 애니메이션은 1개까지만 허용한다. `prefers-reduced-motion: reduce`이면 DS-01, DS-04, DS-05의 연속 모션을 끄고 즉시 상태로 전환한다.
- **아이콘**: `lucide-react`(이미 설치됨)를 기본으로 쓰고, 도장·강줄기·능선은 직접 만든 SVG로 한다. 이모지를 아이콘 대신 쓰지 않는다.
- **일러스트**: 산·강 실루엣은 코드로 만든 SVG path로 한다. 외부 이미지 의존을 최소화한다.
- **문구(한국어 전용)**: 모든 UI 문구는 한국어 해요체로 짧고 따뜻하게 쓴다. 예: "오늘은 이화령을 넘는 날이에요". 영어 UI 용어(Start, Save 등)를 그대로 노출하지 않는다. 거리·속도 단위는 `km`, `km/h`를 쓴다.
