# [기획안] 초간결 감성 투두 리스트 앱: FocusFlow

> **"기록하는 데 드는 에너지는 제로로, 달성했을 때의 도파민은 두 배로"**  
> 사용자가 할 일 관리에 피로감을 느끼지 않고 즉각 몰입할 수 있도록 설계된 UX 중심의 미니멀 Todo List 앱 상세 명세서입니다.

---

## 1. 프로젝트 개요 & 핵심 철학

### 1.1 배경 및 문제 정의
* **문제점**: 시중의 투두 앱(Notion, Jira, Todoist 등)은 기능이 과도하게 많아 태스크 하나를 등록하는 데에도 마감일, 카테고리, 우선순위 등을 설정하느라 피로감을 유발합니다.
* **사용자 이탈 요인**: 할 일을 정리하는 행위 자체가 또 하나의 '일'이 되어 결국 기본 메모장이나 종이 메모로 회귀하게 됩니다.
* **해결책**: **"3초 등록, 1초 완료, 즉각적인 성취감"**에 집중한 초간결 인터랙션 설계.

### 1.2 UX 디자인 원칙
1. **Zero-Friction (무마찰성)**: 앱을 켜자마자 타이핑할 수 있고, 엔터 한 번으로 등록 완료.
2. **Cognitive Calm (인지적 평온함)**: 불필요한 옵션과 UI 요소를 숨기고, 지금 해야 할 일에 시선 집중.
3. **Micro-Delight (감성적 보상)**: 체크박스를 누르는 순간의 촉각적/시각적 피드백으로 루틴 형성 유도.

---

## 2. 타깃 페르소나

| 구분 | 설명 |
| :--- | :--- |
| **주 타깃** | 복잡한 툴에 지쳐 단순하고 직관적인 '오늘의 할 일' 관리가 필요한 학생/직장인 |
| **핵심 니즈** | 생각난 즉시 빠르게 적고, 하나씩 지워나가는 손맛과 오늘 하루의 성취감 시각화 |
| **사용 상황** | 아침 출근/등교 직후 3개~5개 핵심 할 일 정리, 작업 중 수시 체크 |

## 3. 주요 기능 명세 (Core Features)

### 3.1 인라인 퀵 입력 (Natural Quick-Add)
* 앱 진입 시 입력창 자동 포커스 (`autofocus`).
* 입력 후 `Enter` 즉시 목록 최상단 추가.
* **스마트 태깅 (선택적 인라인 파싱)**:
  * `#태그`: 카테고리 자동 분류 (예: `#개발`, `#공부`, `#일상`)
  * `!`: 중요도 표기 (`!` 보통, `!!` 중요, `!!!` 긴급)

### 3.2 제스처 & 단축키 중심 인터랙션
* **체크 클릭**: 완료 토글 (경쾌한 애니메이션 및 취소선 효과).
* **더블클릭**: 텍스트 인라인 즉시 수정 모드 진입.
* **드래그 앤 드롭**: 우선순위에 따른 태스크 순서 자유 재배치.
* **삭제**: 호버 시 노출되는 간결한 아이콘 또는 키보드 Delete.

### 3.3 "One Thing" 집중 모드 (차별화 기능)
* 수많은 할 일 목록에서 오는 압박감을 줄이기 위해 **가장 중요한 1개의 태스크만 화면 중앙에 크게 표시**하는 집중 뷰.
* 완료 시 축하 피드백과 함께 다음 태스크로 부드럽게 전환.

### 3.4 데일리 달성률 링 (Progress Visualizer)
* 화면 상단에 오늘 완료한 태스크 비율(예: 3/4 완료, 75%)을 감성적인 원형/바 프로그레스로 시각화.
* 100% 달성 시 Confetti(축하 파티클) 연출.

### 3.5 로컬 퍼시스턴스 (Local Storage)
* 브라우저 `localStorage`와 실시간 동기화되어 새로고침 및 브라우저 재시작 시에도 데이터 유지.

## 5. 차별화 포인트 (Differentiators)
1. **손맛(Micro-delights)**: 체크 시 바운스 애니메이션과 100% 달성 축하 효과.
2. **One-Thing 모드**: 할 일이 많을 때 시야를 좁혀 인지 과부하를 원천 차단.
3. **무마찰 인터랙션**: 마우스 없이도 `Enter`, `Escape`, `Tab`으로 모든 제어 가능.
