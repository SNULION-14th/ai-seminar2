# 기능 스펙 — 계획 (Plan)

> Status: **Approved** (2026-09-24) · 마일스톤: M1 · 관련: [domain-data.md](domain-data.md), [design-system.md](design-system.md)

## 1. 목적

"며칠 걸려? 어디서 자?"라는 첫 질문에 30초 안에 답한다. 라이더는 조건만 넣고 결과를 손으로 조금 조정한다.

## 2. 사용자 스토리

- P1로서, 출발일과 일수만 넣으면 일자별로 어디서 어디까지 달릴지 보고 싶다.
- P1로서, 가장 힘든 날이 언제인지(이화령 넘는 날) 미리 알고 싶다.
- P2로서, 이번 주말에 탈 구간만 골라 계획하고 싶다.
- 모든 사용자로서, 짠 일정을 내 캘린더에 넣고 싶다.

## 3. 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| PLAN-01 | 입력: 출발일, 일정 방식(**일수 지정** 또는 **하루 목표 거리**), 페이스(`relaxed` 80km/일, `normal` 110km/일, `hard` 150km/일 기준) | P0 |
| PLAN-02 | `splitItinerary`로 일자별 구간을 만든다. 규칙: ① 하루의 끝은 항상 인증센터(또는 `nearbyTown`이 있는 센터) ② 목표 거리에 가장 가까운 센터를 고르되 ③ 새재 구간을 포함하는 날은 목표 거리의 85%로 줄인다(오르막 보정) | P0 |
| PLAN-03 | 결과를 일자 카드 리스트로 보여 준다: 날짜, 출발→도착 센터, 거리, 누적 상승고도, 숙박 거점, 난이도 뱃지 | P0 |
| PLAN-04 | 능선 고도 프로필(DS-02)에 일자 경계를 세로선으로 표시한다 | P0 |
| PLAN-05 | 일자 경계 조정(DS-06): 경계를 앞뒤 인증센터로 옮기면 해당 일자와 다음 일자의 거리를 즉시 다시 계산한다 | P1 |
| PLAN-06 | 부분 계획: 시작/끝 인증센터를 직접 고를 수 있다 (P2 주말 끊어 타기) | P1 |
| PLAN-07 | 준비물 체크리스트: 기본 항목(헬멧, 예비 튜브, 펌프, 보조배터리, 인증수첩 등) + 사용자 추가 항목. 체크 상태를 저장한다 | P1 |
| PLAN-08 | `.ics` 파일 내보내기: 일자마다 종일 이벤트 1개, 설명에 구간/거리/숙박 거점 | P1 |
| PLAN-09 | 계획을 로컬에 저장한다. 계획은 1개만 활성 상태로 두고, 새로 만들면 기존 계획 덮어쓰기를 확인받는다 | P0 |
| PLAN-10 | "계획 JSON 복사" 버튼: 활성 계획을 사람이 읽을 수 있는 JSON(날짜, 출발/도착 센터 이름, 거리, 상승고도, 숙박 거점)으로 클립보드에 복사한다. Google Calendar MCP 데모용 ([mcp.md](mcp.md) §3) | P1 |

## 4. 화면

```text
┌─────────────────────────────┐
│  언제, 며칠 동안 달릴까요?     │  ← Gowun Batang 제목
│  [출발일 📅] [4일 ▾] [보통 ▾] │
│  ( 일정 만들기 )               │
├─────────────────────────────┤
│  ⛰ 능선 고도 프로필 (DS-02)    │  ← 일자 경계 세로선 + 조약돌 핸들
├─────────────────────────────┤
│  DAY 1 · 10/3(금)            │
│  아라서해갑문 → 양평군립미술관  │
│  118km · ↑420m · 숙박: 양평   │
│  DAY 2 ... [고개 뱃지: 이화령] │
├─────────────────────────────┤
│ [체크리스트] [.ics 저장] [시작] │
└─────────────────────────────┘
```

상태: 빈 상태(계획 없음 → 입력 폼 + 예시 일러스트), 생성 중(강줄기 로딩 모션), 결과, 오류(입력값 검증).

## 5. 수용 기준

- [ ] 출발일 + 4일 + normal로 생성하면 DAY 1부터 DAY 4까지 만들어지고, 일자별 거리 합이 전체 경로 거리와 같다
- [ ] 모든 DayPlan의 도착점이 인증센터 ID이다 (단위 테스트)
- [ ] 이화령휴게소를 지나는 날에는 "고개" 뱃지가 표시된다
- [ ] 일수를 1일 또는 20일처럼 비현실적으로 넣으면 안내 문구를 보여 주고 생성은 허용한다(하루 거리 경고)
- [ ] 경계를 한 칸 옮기면 두 일자의 거리가 즉시 바뀌고 합계는 그대로다 (PLAN-05)
- [ ] 새로고침 후에도 계획과 체크리스트가 유지된다
- [ ] 내보낸 `.ics`를 macOS 캘린더나 Google Calendar로 가져오면 일자 수만큼 이벤트가 생긴다
- [ ] "계획 JSON 복사" 결과에 센터 ID가 아니라 한국어 센터 이름이 들어 있고, 일자 수만큼 항목이 있다 (PLAN-10)
