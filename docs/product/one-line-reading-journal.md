# 한줄 독서 기록장 제품 기획

## 제품 정의

**책을 덮은 순간, 느낀 점 한 줄만 남기면 나만의 독서 지도가 쌓이는 앱.**

긴 독후감과 정교한 서재 관리의 부담 없이, 사용자가 책을 읽으며 떠오른 감정과 생각을 책별로 한 줄씩 기록하고 시간이 지난 뒤 다시 발견하도록 돕는다.

## 대상 사용자와 문제

- 읽은 책의 감상을 남기고 싶지만 긴 글을 쓰는 일은 부담스러운 사람
- 읽는 도중 떠오른 생각을 쉽게 잊어버리는 사람
- 완독 권수보다 책과 함께 변한 자신의 생각을 돌아보고 싶은 사람

## 핵심 사용자 경험

기본 흐름은 `책 선택 → 한 줄 작성 → 감정 태그 선택(선택) → 저장`이다.

- 앱을 열고 10초 안에 기록을 끝낼 수 있어야 한다.
- 읽는 중인 책과 완독한 책 모두에 기록할 수 있다.
- 태그, 별점, 공개 설정은 기록을 방해하지 않는 선택 기능이다.
- 저장된 기록은 타임라인과 회상 알림을 통해 다시 만난다.

## 주요 기능

| 기능 | 설명 | 사용자 가치 |
| --- | --- | --- |
| 한줄 기록 | 책별 짧은 감상·생각 기록 | 빠르고 부담 없는 기록 |
| 책 등록 | 제목 검색, ISBN 스캔, 직접 입력 | 기록 시작 마찰 감소 |
| 독서 상태 | 읽고 싶음 / 읽는 중 / 완독 | 개인 독서 흐름 파악 |
| 감정·인상 태그 | 예: 위로됨, 낯설다, 다시 읽고 싶다 | 기록 회상 지원 |
| 타임라인 | 날짜 순으로 기록 표시 | 생각과 독서 여정 회고 |
| 책장 | 상태·장르·태그별 책 모아보기 | 개인 서재 관리 |
| 회상 알림 | 과거 같은 날의 기록 재노출 | 정서적 연결과 재방문 |
| 검색 | 책 제목·저자·기록 문구 검색 | 기록 재발견 |
| 월간 리캡 | 권수, 기록 수, 자주 쓴 감정 요약 | 습관 형성과 성취감 |

## 화면 구성

### 홈: 오늘의 기록

- “오늘, 어떤 문장을 남기고 싶나요?”라는 진입 문구와 빠른 기록 입력
- 최근 기록 3개와 현재 읽는 책
- 하단 탐색: 홈 / 책장 / 기록 / 마이

### 기록 작성

- 책 표지와 제목, 한줄 입력창, 선택 태그, 저장
- 공개 범위는 기본 비공개
- 부가 설정은 보조 위치에 두며, 텍스트 작성이 첫 시각 초점이다.

### 책장

- 읽고 싶음 / 읽는 중 / 완독 탭
- 표지 중심 목록 및 장르·연도·태그 필터
- 책 상세에서 해당 책의 기록을 시간순으로 제공

### 기록 타임라인

- 날짜별 기록 카드: 표지 썸네일, 문장, 태그, 작성일
- 과거 기록을 무작위로 다시 보는 기능 제공

### 월간 리캡과 마이

- 이번 달 읽은 권수, 기록 수, 자주 선택한 감정, 기억에 남는 문장
- 기록 데이터 백업·내보내기와 알림 설정

## 차별화 포인트

1. **독후감이 아닌 생각의 스냅샷**: 완독과 긴 리뷰를 전제하지 않는다.
2. **기록을 다시 만나는 경험**: 저장보다 회상에 가치를 둔다.
3. **조용한 개인 공간**: 팔로워·좋아요·경쟁이 기본 경험을 점유하지 않는다.
4. **감정 기반 재탐색**: 장르나 별점뿐 아니라 당시의 감정과 상황으로 책을 다시 찾는다.

## MVP 범위

첫 출시에는 아래에 집중한다.

1. 책 직접 등록 및 검색
2. 한줄 기록 작성·수정·삭제
3. 읽기 상태 관리
4. 책별 기록 모아보기
5. 날짜별 기록 타임라인
6. 기본 검색
7. 과거 기록 회상 알림

월간 리캡, 공유 카드, ISBN 스캔, 고급 통계는 사용자 반응 검증 후 확장한다.

## 성공 지표

- 가입 후 첫 기록 작성 비율
- 사용자당 주간 한줄 기록 수
- 7일 및 30일 재방문율
- 회상 알림 클릭률
- 책당 평균 기록 수
- 기록 후 다음 기록까지 걸리는 시간

가장 중요한 성공 기준은 사용자가 부담 없이 꾸준히 한 줄을 남기는 것이다.
