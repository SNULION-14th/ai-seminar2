# Trip Pocket — 제품 스펙

## 한 줄 소개
유럽 도시 + 여행 날짜를 고르면 **날씨 → 짐 체크리스트 → 가볼 곳**을 한 화면에 정리해 주는 초간단 여행 플래너.

## 타깃 사용자
독일 체류 중 주말마다 근교 도시로 짧게(1~3박) 여행 가는 학생. 준비 시간이 짧아 "날씨 보고 짐 싸고 갈 곳 고르기"를 빠르게 끝내고 싶다.

## 핵심 기능 (MVP)
| # | 기능 | 설명 |
| --- | --- | --- |
| F1 | 도시·날짜 선택 | 시드 도시 목록에서 1개 선택, 시작/종료일 입력 (최대 7일) |
| F2 | 날씨 카드 | 날짜별 최고/최저기온, 강수, 날씨 아이콘. 16일 이내면 **예보**, 그 이후면 **작년 같은 날짜 실측**을 참고값으로 표시 (라벨로 구분) |
| F3 | 짐 체크리스트 | 날씨 규칙으로 자동 생성(기온·비·눈) + 직접 추가/삭제, 체크 가능 |
| F4 | 가볼 곳 | 도시별 추천 장소(카테고리 필터), 담기/빼기, Google 지도 링크 |
| F5 | 저장 | 도시·날짜·체크 상태를 localStorage에 저장해 새로고침 후에도 유지 |

## 화면 구성 (단일 페이지)
1. 헤더: 서비스명 + 도시 선택 + 날짜 입력
2. 날씨 스트립: 날짜별 카드 가로 나열 + 데이터 출처 라벨
3. 2열 본문: 왼쪽 짐 체크리스트 / 오른쪽 가볼 곳
4. 모바일(≤720px)에서는 1열

## 짐 자동 생성 규칙
- 여행 기간 중 최저기온 ≤ 5°C → 패딩/두꺼운 외투, 장갑·목도리
- 최저기온 ≤ 0°C → 핫팩, 방한 양말
- 최고기온 ≥ 22°C → 반팔, 선크림
- 강수확률 ≥ 50% 또는 강수량 ≥ 1mm 인 날 존재 → 우산, 방수 신발
- 날씨 코드가 눈(71~77, 85~86) → 미끄럼 방지 신발
- 항상: 여권, 충전기·어댑터, 교통카드/Deutschlandticket

## 제외 범위 (Non-goals)
로그인, 서버 DB, 예약/결제, 다중 도시 일정 최적화.
