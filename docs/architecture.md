# 프로젝트 구조

## 범위

개인의 컴퓨터에서 실행하는 카드뉴스 제작 도구다. 회원가입·데이터베이스·AI API 서버·인스타그램 자동 게시 기능은 포함하지 않는다.

| 영역 | 책임 |
| --- | --- |
| `src/` | 입력·레퍼런스 저장, 현재 작업 결과 확인, 미리보기와 Figma용 JSON 복사 |
| `vite-brief.ts` | 로컬 브리프 저장, 작업 식별자와 결과의 대응 확인 |
| `shared/` | 입력·레퍼런스·배치 계약, 디자인 규칙 추출과 검증 |
| `figma-plugin/` | 선택한 프레임 읽기, 검증된 배치 렌더링, PNG 내보내기 |
| `tests/` | 공개 가능한 예시와 재현 가능한 동작 테스트 |

## 파일 흐름

1. 플러그인이 원본에서 레퍼런스 JSON을 추출한다. 웹앱은 붙여넣은 레퍼런스의 작은 누락을 보완하고 사용할 수 없는 레이어를 경고한다.
2. 웹앱이 입력과 레퍼런스를 `/api/brief`로 보낸다. 서버는 작업 UUID와 레퍼런스 해시를 만들고 `brief/latest.json`을 원자적으로 교체한다.
3. 에이전트가 브리프의 `prompt`를 읽고 `brief/layout.json`을 만든다.
4. `/api/layout`은 최신 브리프와 결과의 식별자·레퍼런스·장수·순서를 확인한다. 응답에는 저장 당시 입력과 레퍼런스가 함께 담긴다.
5. 웹앱은 화면에 기억한 작업 ID로 조회를 제한하지 않고 저장된 결과를 바로 보여 준다. 현재 입력·레퍼런스와의 차이는 안내만 하며 폼을 덮어쓰지 않는다. 미리보기·배치 검증·Figma 복사는 결과의 입력과 레퍼런스를 사용한다. 편집 중 늦게 도착한 응답은 무시한다.
6. Figma에는 `{ kind: 'cardnews', deck, manifest, referenceMode }`를 복사해 가져간다. 사진이 필요하면 플러그인에서 파일을 별도로 선택한다.

## 규칙

- 검증과 레퍼런스 보완은 `shared/`의 순수 함수로 공유한다. 브라우저·서버·플러그인에서 같은 계약을 사용한다.
- 수작업 레퍼런스의 프레임·레이어 이름은 중복을 허용하고 순서를 유지한다. 메타데이터·선택 목록·글자 예산 등 작은 누락은 안정된 기본값이나 원문으로 보완한다. 숫자 문자열·짧은 색 표기는 변환하고, 디자인 시스템이 없으면 프레임에서 다시 추출한다. 불명확한 글꼴은 `mixed`로 남긴다.
- 좌표가 없어 사용할 수 없는 레이어만 제외하고 `notes`에 경고한다. 프레임 자체가 없거나 판형이 잘못된 경우, 지원하지 않는 버전·파손된 JSON·자원 상한 초과는 중단한다. 기본값 보완으로 커진 명세도 2 MiB 상한을 지켜야 한다. 생성된 배치의 넘침·가림·장수·작업 식별자 검사는 유지한다.
- 정상 명세는 값과 배열 순서를 변경하지 않는다. 보완 결과를 다시 읽어도 같은 결과가 나와야 한다. 서버는 이 보완된 명세를 저장하고 해시를 계산하므로 현재 시각·무작위 값·반복되는 경고 추가로 명세를 변경하지 않는다.
- 배치 자유도는 `strict` / `body` / `free`이며, 화면에서는 레퍼런스 유지 / 본문 재구성 / 전체 재구성으로 표시한다.
- 내부 `templateMode`, `templateHash` 이름은 저장 형식 호환을 위해 유지한다.
- 입력·출력 파일은 로컬 개인정보 자료다. 정적 웹 배포 대상으로 취급하지 않는다.
- 개발 서버는 루프백 주소에 바인딩하고 동일 출처의 브라우저 요청과 로컬 CLI 요청만 받는다. `brief/`·`renders/`·환경변수·개인 설정은 HTTP 정적 경로와 `/@fs`에서도 제공하지 않는다.
- `npm run build`와 `npm run preview`는 화면 빌드 확인용이다. 파일 API는 `npm run dev`에만 붙는다.
- 코드 생성 과정에서 사용하는 MCP와 앱 실행 중의 기능을 구분한다. 현재 Figma 가져오기는 개발 플러그인 방식이며 MCP 사용 실적을 뜻하지 않는다.

## 과제의 MCP 사용 기록

Figma MCP로 디자인 조회·검토, GitHub MCP로 브랜치·PR 작업을 수행했다면 PR에 실제 도구 이름, 사용 목적, Figma 파일·프레임 링크와 PR 링크를 기록한다. 설치만 했거나 아직 사용하지 않은 도구를 사용했다고 적지 않는다. 토큰과 개인 설정 파일은 첨부하지 않는다.
