# [PRD] FocusFlow : 미니멀 투두리스트 제품 기획안

> **"복잡함을 덜어내고, 오늘 끝내야 할 단 하나에 집중하게 돕는 초경량 투두리스트"**

---

## 1. 프로젝트 개요 & 문제 정의

### 1.1 배경 및 문제점 (Problem Statement)
* **생산성 앱의 역설 (Productivity Paradox):** Notion, Todoist, Things3 등 강력한 생산성 도구들은 기능(우선순위, 태그, 프로젝트 폴더, 캘린더 연동 등)이 과도하게 많아 할 일을 '관리하는 일' 자체가 또 다른 스트레스가 됩니다.
* **Todo Guilt (할 일 목록 죄책감):** 계속해서 쌓여만 가는 끝없는 체크리스트는 사용자에게 무력감과 피로감을 줍니다.
* **높은 기록 진입장벽:** 앱을 켜고, 날짜를 고르고, 카테고리를 설정하는 동안 할 일 기록의 본질적인 속도감이 사라집니다.

### 1.2 제품 비전 (Product Vision)
> **"생각을 비우는 데는 1초, 몰입하고 끝내는 데는 100% 집중"**  
> 가장 단순하지만 매일 켜고 싶어지는 직관적인 인터랙션과 성취감 중심의 UX를 제공합니다.

---

## 2. 타겟 페르소나 & 핵심 UX 원칙

### 2.1 타겟 사용자 (Persona)
* **미니멀리스트 직장인/학생:** 복잡한 도구보다 당장 오늘 해야 할 3~5가지 일을 빠르게 정리하고 싶은 사용자.
* **생산성 앱 이탈자:** 기능이 많아 설정하다가 쉽게 지쳐서 포기했던 경험이 있는 사용자.

### 2.2 핵심 UX 원칙 (Core UX Principles)
1. **Zero Friction (무마찰 인풋):** 앱 실행 후 할 일을 적기까지 탭 수는 단 1회 이하(즉시 키보드 활성화 옵션).
2. **Cognitive Load Relief (인지 부하 최소화):** '오늘(Today)'과 '나중에(Someday)' 두 가지 컨텍스트만 제공.
3. **Dopamine Loop (성취감 극대화):** 체크하는 순간 기분 좋은 햅틱/애니메이션 인터랙션으로 즉각적인 보상 제공.

## 3. 핵심 기능 정의 (Feature Scope)

| 구분 | 기능명 | 상세 설명 | 사용자 가치 |
| :--- | :--- | :--- | :--- |
| **P0 (필수)** | **원스텝 퀵 캡처** | 앱 하단 상시 고정 입력창 또는 앱 실행 즉시 입력 포커싱 | 할 일이 생각났을 때 2초 내 기록 완료 |
| **P0 (필수)** | **2-버킷 분류** | 오늘 해야 할 일(Today) vs 언젠가 할 일(Later/Someday) | 복잡한 날짜 설정 스트레스 제거 |
| **P0 (필수)** | **직관적 제스처** | 오른쪽 스와이프: 완료 / 왼쪽 스와이프: 내일로 미루기 or 삭제 | 버튼 클릭보다 빠른 물리적 쾌감 |
| **P1 (차별화)**| **Top 3 집중 모드** | 오늘 할 일 중 가장 중요한 3가지만 상단 핀 고정 및 강조 | 멀티태스킹 방지, 진짜 중요한 일 선행 |
| **P1 (차별화)**| **나이트 클린업** | 자정/퇴근 시간에 미완료 태스크를 부담 없이 정리하는 넛지 | 다음 날 아침 깨끗한 상태로 새 출발 보장 |
| **P2 (부가)** | **마이크로 리워드** | 올클리어 시 제공되는 부드러운 컨페티 애니메이션 및 햅틱 | 하루를 끝냈다는 감성적 피드백 |

## 4. 사용자 흐름 (User Flow)

```text
[앱 실행]
   │
   ├─► (Top 3 비어있음) ──► 하단 입력창에 입력 시 'Today Focus'로 자동 배치
   │
   └─► (Top 3 꽉 참)   ──► 하단 입력창에 입력 시 '일반 할 일(Other Tasks)' 또는 'Later'로 배치
         │
         ▼
     [리스트 조작]
       ├─ 오른쪽 스와이프: 완료 (햅틱 진동 + 취소선 + 카운트 상승)
       ├─ 왼쪽 스와이프  : 내일로 미루기 / 보관함 이동
       └─ 길게 누르기(드래그) : 우선순위 순서 재배치
         │
         ▼
   [오늘 할 일 전부 완료 시] ──► 잔잔한 축하 모션 & 올클리어 완료 메시지
```

## 5. 화면 설계 (Screen Layout & Wireframe)

단일 화면(Single-View) 중심의 미니멀 인터페이스를 지향합니다.

### 5.1 메인 화면 레이아웃

```text
+------------------------------------------+
|  FocusFlow                     [설정 아이콘] |
|  "오늘도 차근차근, 세 가지만 끝내봐요."     |
|                                          |
|  [======= 66% (2/3 완료) =======]        |
|                                          |
|  📌 TODAY'S FOCUS (최대 3개 집중 권장)     |
|  [v] 기획안 초안 작성하기 (완료)           |
|  [ ] 14:00 팀 싱크 미팅 준비               |
|  [ ] 운동 30분 달리기                      |
|                                          |
|  📋 OTHER TASKS (오늘의 보조 업무)         |
|  [ ] 영수증 경비 처리                    |
|  [ ] 메일 회신 3건                       |
|                                          |
|  --------------------------------------- |
|  [ + 할 일을 입력하세요...           ] [등록] |
+------------------------------------------+
```

### 5.2 주요 인터랙션 디테일
* **체크 액션 (Completion):**
  * 체크박스를 누르거나 우측으로 스와이프하면 경쾌한 '틱' 햅틱 피드백과 함께 글자에 취소선이 그어지고, 0.3초 뒤 완료 목록 아래로 부드럽게 이동.
* **진행률 바 (Progress Bar):**
  * 하루 목표 달성률을 색상 그라데이션 프로그레스 바로 직관적으로 시각화.
* **하단 인풋바 (Input Field):**
  * 키보드가 올라올 때 부드럽게 화면 하단에 플로팅되며, Enter를 누르면 연속 등록 가능.

## 6. 핵심 차별화 포인트 (Differentiators)

1. **'3가지 룰 (The Rule of 3)' 집중 시스템**
   * 끝없는 리스트는 실행력을 떨어뜨립니다. FocusFlow는 메인 뷰에 **'오늘 가장 중요한 3가지'**를 강제로 지정하게 유도하여 사용자가 선택의 고통 없이 당장 1번에 착수하도록 돕습니다.
2. **죄책감 없는 밤 정리 (Evening Clean-up & Guilt-Free Rollover)**
   * 대부분의 투두앱은 어제 못 한 일이 빨간 글씨(Overdue)로 남아 사용자에게 패배감을 줍니다.
   * FocusFlow는 밤이 되면 조용히 묻습니다: *"오늘 못 끝낸 일 2건, 내일 아침에 다시 도전할까요, 아니면 언젠가 할 일로 보관할까요?"*
   * 빨간 경고창 대신 부드러운 재조정 기회를 제공하여 매일 아침을 0(Zero)에서 산뜻하게 시작하게 합니다.
3. **피젯 토이(Fidget Toy) 같은 손맛의 마이크로 인터랙션**
   * 리스트를 지울 때, 완료할 때, 드래그할 때 전해지는 물리 엔진 기반의 미세한 탄성 애니메이션과 정교한 사운드/진동 디자인을 적용하여 '앱을 켜고 완료 체크를 하고 싶어지는 중독성'을 구축합니다.

## 7. 성공 지표 (Success Metrics) & 릴리즈 로드맵

### 7.1 핵심 지표 (KPIs)
* **D+1 / D+7 리텐션 (Retention):** 7일 후에도 매일 할 일을 1개 이상 작성하는 비율 (목표: D+7 > 35%)
* **Task Completion Rate (완료율):** 등록된 태스크 대비 완료율 (목표: 65% 이상)
* **Time-to-First-Task (등록 속도):** 앱 실행부터 첫 할 일 등록 완료까지 소요 시간 (목표: 4초 이내)

### 7.2 마일스톤 (Phased Roadmap)
* **Phase 1 (MVP - 2주):** 단일 화면, 로컬 스토리지 기반 CRUD, 스와이프 제스처, Top 3 고정 기능
* **Phase 2 (UX 고도화 - 2주):** 햅틱/애니메이션 튜닝, 나이트 클린업(자정 리셋/이관 알림), 다크모드
* **Phase 3 (확장성 검증 - 4주):** 홈 화면 위젯(iOS/Android), 클라우드 동기화 및 백업
