# Google Calendar MCP 데모 (L1)

> 스펙: [mcp.md](../specs/mcp.md) §3 Google Calendar MCP · 진행: Lead · 일시: 2026-09-25 00:09 KST

## 1. 시나리오

1. 앱과 같은 도메인 함수로 계획을 만든다: `splitItinerary({ startDate: '2026-10-03', pace: 'normal', mode: 'days', days: 5 })` (PLAN-02)
2. "계획 JSON 복사"(PLAN-10)와 같은 함수 `buildReadablePlanJson`으로 JSON을 만든다
3. Claude에게 요청한다: **"이 일정 내 캘린더에 넣어줘"**
4. Claude가 Google Calendar MCP `create_event`로 일자별 종일 이벤트를 만든다

브라우저(Playwright MCP)는 qa 전용이라, Lead는 앱 UI 대신 같은 함수를 vitest 러너로 직접 호출해 JSON을 얻었다.

## 3. 결과: 생성된 이벤트 (primary 캘린더, 종일, 한가함 표시)

| 날짜 | 제목 | 설명 |
| --- | --- | --- |
| 2026-10-03 (토) | [강따라 633] DAY 1 아라서해갑문→이포보 | 거리 124km · 상승고도 37m · 숙박 거점: 이포 |
| 2026-10-04 (일) | [강따라 633] DAY 2 이포보→수안보온천 | 거리 112km · 상승고도 155m · 숙박 거점: 수안보 |
| 2026-10-05 (월) | [강따라 633] DAY 3 수안보온천→구미보 | 거리 122km · 상승고도 494m(이화령 포함) · 숙박 거점: 구미 |
| 2026-10-06 (화) | [강따라 633] DAY 4 구미보→합천창녕보 | 거리 123km · 상승고도 178m · 숙박 거점: 적포 |
| 2026-10-07 (수) | [강따라 633] DAY 5 합천창녕보→낙동강하굿둑 | 거리 152km · 상승고도 162m · 숙박 거점: 부산 |

계획 일수 5일 = 이벤트 5개. `list_events`(fullText "강따라 633", Asia/Seoul)로 날짜를 다시 조회해 확인했다.

## 4. 진행 중 발견한 문제

- 처음에 `startTime`을 `2026-10-03T00:00:00+09:00`처럼 KST 자정으로 넘기자, 종일 이벤트가 UTC 날짜로 잘려 **모두 하루 앞(10-02부터)** 에 만들어졌다.
- `update_event`로 `2026-10-03T00:00:00Z`처럼 UTC 자정 기준 날짜를 다시 넘겨 바로잡았다.
- 교훈: Calendar MCP로 종일 이벤트를 만들 때는 날짜를 UTC 자정(`...T00:00:00Z`)으로 넘긴다. 앱의 `.ics` 내보내기(PLAN-08)는 `VALUE=DATE`를 쓰므로 이 문제와 무관하다.

## 5. 캡처

Google Calendar 화면 캡처는 로그인된 브라우저가 필요해 생략하고, MCP 조회 결과(위 표)로 대신한다. 이벤트는 데모 확인 후 캘린더에서 지워도 된다.
