# UX 규칙과 화면 구성

## 핵심 흐름

```text
Calendar 연결 → 조율 조건 입력 → 링크 공유 → 참석자 응답
→ 후보 비교 → 주최자 확정 → Calendar 이벤트 생성
```

## 화면

- **홈**: 진행 중인 조율, 확정된 일정, `새 일정 조율` CTA와 응답 현황을 표시한다.
- **조율 만들기**: 제목, 참석자, 날짜 범위, 소요 시간, 선호 시간대, GitHub 링크를 입력한다.
- **후보 시간·투표**: 최대 세 후보와 참석자별 `가능/애매함/불가/미응답`만 표시한다.
- **확정 완료**: 확정 시간, Calendar 이벤트 링크, GitHub 작업 링크를 제공한다.

## UX 원칙

- 캘린더의 세부 일정은 절대 표시하지 않는다.
- 외부 이벤트 생성 전에는 대상 시간과 생성 사실을 다시 확인한다.
- 실패 시 원인·재시도 가능 여부·다음 행동을 함께 안내한다.
