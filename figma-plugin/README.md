# Figma 플러그인

설치와 사용법은 [저장소 README](../README.md)를 보세요. 여기에는 플러그인이 하는 일만 적습니다.

## 세 가지 일

| 탭 | 하는 일 |
| --- | --- |
| **① 레퍼런스 읽기** | 선택한 카드 프레임을 읽어 디자인 명세로 만듭니다. 원본은 바뀌지 않습니다 |
| **읽은 대로 다시 그리기** | 읽은 명세를 원본 옆에 재현합니다. 다른 곳 = 읽기가 놓친 것 |
| **② 카드 만들기** | 에이전트가 짠 배치를 그립니다. 그리기 전에 다시 검사합니다 |

## 글자 예산을 재는 방식

현재 페이지의 빈 공간에 만든 **임시 텍스트 복제본**에 문구 길이를 바꿔 넣으며 상자를 넘지 않는 최대치를 이분 탐색합니다.
원본의 문구·서식·크기·위치와 부모의 자동 배치는 수정하지 않습니다. 임시 노드는 성공·실패 모두 제거합니다.
폰트는 원본과 같으며, 혼합 서식이나 측정 실패 시에는 경고와 함께 원문 글자 수를 예산으로 사용합니다.

개발자 모드의 CSS로는 이 값을 얻을 수 없습니다. 그래서 읽기가 따로 있습니다.

레퍼런스를 가져올 때 프레임·레이어 이름의 중복과 부가 정보 누락을 허용합니다. 가능한 값은 보완하고, 읽을 수 없는 레이어만 제외해 참고 사항에 표시합니다. 이름을 통일하거나 모든 레이어를 다시 정리할 필요는 없습니다.

카드 프레임은 다른 프레임·그룹·섹션 안에 있어도 선택해 읽을 수 있습니다. 부모 종류로 카드 여부를 판정하지 않습니다. 직접 선택한 프레임의 크기를 판형으로 사용하고, 부모·자식 프레임을 함께 선택하면 부모만 한 번 읽습니다.

## 지키는 것

- 현재 파일의 **현재 페이지**에만 씁니다.
- 기존 최상위 노드의 오른쪽 빈 자리에 새 묶음을 놓습니다. 기존 작업을 옮기거나 지우지 않습니다.
- 도중에 실패하면 이번 실행이 만든 노드만 지웁니다.
- 실제 글꼴로 그린 뒤 텍스트 높이·카드 밖 넘침·텍스트 겹침을 다시 검사합니다. 넘치면 문구나 배치를 수정하도록 오류를 표시하고 이번 생성 전체를 제거합니다.
- 읽기·다시 그리기·생성·내보내기는 한 번에 하나씩 실행합니다. 실행 중에는 중복 작업과 닫기 버튼을 잠시 막습니다.
- 폰트는 파일에 넣지 않고 이름으로 지정합니다. 레퍼런스가 쓰던 폰트를 그대로 씁니다.
- 외부와 통신하지 않습니다(`networkAccess.allowedDomains: ["none"]`). 토큰도 계정도 필요 없습니다.

## 오류가 났을 때

Figma가 띄우는 대화상자는 내용을 복사할 수 없습니다. 그래서 모든 오류를 **플러그인 창 안에** 띄웁니다.
**오류 글자를 클릭하면 전체가 복사**됩니다.

`실제 높이가 배치 상자를 넘습니다`는 웹앱의 추정과 Figma 글꼴의 실제 줄바꿈이 달랐다는 뜻입니다.
해당 문구를 줄이거나 `rect.height`와 주변 배치를 조정해 다시 생성하세요. `lineHeight`를 생략하면 해당 글꼴의 기본 줄높이를 사용합니다.

단, 플러그인이 뜨기도 전에 나는 오류(manifest 문제)는 Figma가 직접 띄웁니다. 그건 화면을 캡처해 주세요.
